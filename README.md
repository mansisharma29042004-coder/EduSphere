
# EduSphere Student Management System

## Project Description
EduSphere is a full-stack student management
web application developed using Python Flask,
MySQL, HTML, CSS and JavaScript.

## Technologies
- Python
- Flask
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap-free custom responsive design

## Features
- Admin authentication
- Student registration and login
- Admin dashboard
- Student CRUD operations
- Course listing
- Attendance management
- Fee management
- Examination results
- Student profile
- Reports

## Installation

1. Install Python and XAMPP.
2. Start Apache and MySQL.
3. Install dependencies:

   pip install -r requirements.txt

4. Configure the .env file.
5. Initialize database:

   python database.py

6. Run application:

   python app.py

7. Open:

   http://127.0.0.1:5000
